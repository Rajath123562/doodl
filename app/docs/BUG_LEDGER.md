## Severity Classification Rules

- **CRITICAL**: Security vulnerability, secret word leakage, data corruption, persistent game stall, crash loop, or unauthorized privilege escalation. Release blocking.
- **HIGH**: Feature non-functional, disconnect without recovery, score calculation discrepancy, or severe layout breakage on primary viewports. Release blocking.
- **MEDIUM**: Secondary cosmetic flaw, transient animation jitter, or non-blocking edge case. Fixed prior to general availability.
- **LOW**: Minor polish item or enhancement.
