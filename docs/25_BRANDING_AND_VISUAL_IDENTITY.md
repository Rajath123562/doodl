# 25 — Original Doodl visual direction and asset production brief

**Brand position:** modern group party game, fun with friends, creative but never messy UI. “doodl.” is a provisional codename, not guaranteed cleared for commercial trademark/domain use. Assess name clearance before public branding. Do not copy specific competitor logos, mascots, identifiable characters or interface assets.

## Distinctive attributes

- Friendly hand-drawn details used **sparingly** at edges of hero/empty states; gameplay canvas remains pristine.
- Warm off-white background, ink-dark text, coral highlight with mint/lilac/sun secondary markers, strong accessibility contrast.
- Playful but disciplined typography, restrained rounding and subtle elevation. Modern product navigation, not a financial dashboard or flashy gaming launcher.
- Diverse original avatar builder based on vector parts and user-selected palettes without guessing sensitive traits; emoji sticker library only original or Unicode symbols with licensing considerations.
- Game motion signals genuine state transitions: word selected, match found, guessed correctly, one turn complete. Do not continuously animate whole page or confetti during drawing.

## Deliverables from frontend designer agent

Write design tokens source; reusable buttons/inputs/tool selectors/room cards and avatar elements; Home/Lobby/Game/Results/Daily/Gallery/Avatar/QuickPlay/Duels/Chaos/Teams/Rules screens; responsive mobile layouts; all states from `02` and `19`; deliberate motion, accessibility, focus/hover/tap; original iconography and branding assets with source/license manifest. Provide screenshots at required sizes and compare visually. An inactive “See Demo” button is not an implementation of a game mode.

## Good acceptance criteria

First-time user can recognize start path in <5 seconds; join invite and nickname friction low; center canvas receives priority; no empty decorative panels; multiple player scores glanceable; actionable network errors; mobile on-screen keyboard not hiding guess send; toast and match results visually coherent; original assets licensed; design appears intentionally crafted rather than template-generated.
